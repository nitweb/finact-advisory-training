# 📘 FINACT Advisory & Training

FINACT Advisory & Training is a platform focused on providing professional advisory services and practical training in finance, accounting, and business systems.

---

## 🚀 Features (Planned)

- Advisory services for businesses  
- Financial & accounting training programs  
- Online course management  
- Resource sharing (PDFs, guides, tools)  
- Client and student management system  

---

## 🛠️ Tech Stack

- Backend: Laravel  
- Frontend: Blade / Tailwind CSS (planned)  
- Database: MySQL  

---

## 📂 Project Setup

```bash
git clone https://github.com/nitweb/finact-advisory-training/
cd finact-advisory-training

composer install
cp .env.example .env
php artisan key:generate

php artisan migrate
php artisan serve
